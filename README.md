<div align="left">

  <p>
    계란을 삶을 때마다 몇 분을 삶아야 할지, 언제 불을 꺼야 할지 헷갈린 적 없으신가요?<br>
    <strong>에그타임</strong>은 촉촉한 반숙부터 단단한 완숙까지 원하는 익힘 정도를 스와이프로 고르기만 하면<br>

    여기에 계란으로 만들 수 있는 다양한 <strong>레시피</strong>까지 담아, 삶은 계란의 그다음 한 끼까지 책임집니다.

## 📱 주요 기능

### ⏱️ 익힘 정도별 계란 타이머
* **4단계 익힘 선택** : 반숙(6분), 부드러운 반숙(8분), 중간 익힘(10분), 완숙(12분)을 좌우 **스와이프**로 간편하게 선택합니다.
* **직관적인 타이머** : 시작 / 일시정지 / 재개 / 다시 시작 / 초기화까지, 조리 상태에 맞춰 버튼과 안내 문구가 자연스럽게 전환됩니다.

### 🌙 백그라운드에서도 정확한 시간
* **목표 시각 기반 계산** : 남은 시간을 1초씩 빼는 방식이 아닌 **종료 목표 시각(deadline)** 을 기준으로 계산하여, 앱이 백그라운드에 있어도 시간이 어긋나지 않습니다.
* **상태 복원** : 앱을 강제 종료했다 다시 켜도 진행 중이던 타이머를 그대로 이어서 보여주며, 일시정지 상태도 1시간까지 복원합니다.

### 🔔 완료 알림
* **로컬 푸시 알림** : 조리가 끝나면 즉시 알림으로 알려드려, 다른 일을 하다가도 완벽한 타이밍을 놓치지 않습니다.
* **포그라운드 대응** : 앱이 켜져 있을 때도 사운드 모드에 맞춰 배너 · 소리 · 진동을 직접 처리해 일관된 완료 경험을 제공합니다.

### 🍳 계란 레시피
* **카테고리별 탐색** : 삶은 계란 · 프라이 · 스크램블 · 오믈렛 등 분류별로 원하는 레시피만 골라볼 수 있습니다.
* **상세 레시피** : 조리 시간, 난이도, 재료, 조리 순서까지 한눈에 확인할 수 있습니다.
* **북마크 저장** : 마음에 드는 레시피를 저장해 두고 언제든 다시 꺼내볼 수 있습니다.

### ⚙️ 세심한 설정
* **사운드 모드** : 진동 / 소리 / 진동 및 소리 / 끄기 중에서 선택할 수 있습니다.
* **종료음 선택** : 여러 종류의 완료 알림음 중 원하는 소리를 고를 수 있습니다.
* **알림 권한 · 앱 정보 · 개인정보 처리방침 · 문의하기** : 사용에 필요한 정보와 설정을 한곳에 모았습니다.

### 🌏 다국어 지원
* **한국어 · 영어** : String Catalog 기반으로 두 개 언어를 지원합니다.

## 💡 기술적 의사결정 (iOS)

### 아키텍처 : TCA (The Composable Architecture)
* **단방향 데이터 흐름** : View → Action → Reducer → State로 이어지는 단방향 흐름을 강제하여, 타이머의 여러 상태(대기 · 진행 · 일시정지 · 완료) 전환에서도 UI 일관성을 유지했습니다.
* **기능 조합(Composition)** : 타이머 · 레시피 · 설정을 각각의 `Reducer`로 분리한 뒤 `Scope`로 조합하여, 기능별 관심사를 명확히 나누고 재사용성과 테스트 용이성을 확보했습니다.

### 의존성 관리 : TCA Dependencies
* **부수효과 격리** : 알림, 타이머 저장/복원, 사운드 설정, 북마크, 앱스토어 조회 등 외부 의존성을 `@Dependency`로 주입하여 Reducer를 순수하게 유지했습니다.
* **교체 가능성** : 의존성을 프로토콜/클라이언트 형태로 추상화해, 테스트 및 프리뷰 환경에서 손쉽게 대체할 수 있도록 설계했습니다.

### 시간 정확도 : 목표 시각(Deadline) 기반 계산
* **백그라운드 오차 제거** : 남은 시간을 1초씩 차감하는 대신 **종료 목표 시각(deadline)** 을 저장하고 매 tick마다 현재 시각과의 차이를 다시 계산했습니다. 이를 통해 앱이 백그라운드로 내려가 타이머가 멈춰도 실제 경과 시간이 정확히 반영됩니다.
* **상태 영속화** : 진행 · 일시정지 상태를 스냅샷으로 저장해, 앱을 강제 종료 후 다시 실행해도 타이머를 자연스럽게 복원합니다. (일시정지는 1시간까지 복원 후 만료 처리)

### 비동기 처리 : Swift Concurrency & ContinuousClock
* **테스트 가능한 타이머** : `ContinuousClock`을 주입해 시간 흐름을 제어 가능하게 만들어, 실제 대기 없이 타이머 로직을 검증할 수 있도록 설계했습니다.
* **취소 관리** : `cancellable(id:)` 기반으로 카운트다운 이펙트를 명확히 취소·재시작하여, 상태 전환 시 중복 실행이나 누수를 방지했습니다.

### 알림 경험 : Local Notification + 포그라운드 처리
* **일관된 완료 알림** : 백그라운드에서는 로컬 푸시로, 포그라운드에서는 델리게이트에서 배너와 소리/진동을 직접 제어했습니다.
* **무음 스위치 대응** : 알림의 기본 사운드는 무음 스위치를 따르므로, 소리 모드에서는 앱이 직접 완료음을 재생해 사용자가 설정한 사운드 모드를 항상 존중하도록 처리했습니다.
